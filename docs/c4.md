# C4 architecture — local-coding-slm

C4 views of the system in [spec.md](../spec.md). Placeholders only. No
hostnames, LAN addresses, or SKUs.

Halo is **Phase 4**: the same containers, a different inference host.
See [roadmap.md](roadmap.md).

## Level 1 — System context

The developer and a **desktop** premium agent stay in control. The
private lab does bounded generation. Cloud-hosted agents and public
tunnels are outside the system and must not reach Ollama.

```mermaid
C4Context
title System context — private local coding SLM

Person(dev, "Developer", "Chooses tasks, reviews local output, applies patches")

System_Ext(premium, "Premium model API", "Cursor / Copilot / Claude cloud models. Plans and reviews. Never pointed at Ollama")

System(lab, "Private coding lab", "Desktop IDE + local-coding-slm MCP + private Ollama")

System_Ext(cloud_agent, "Cloud-hosted agents", "Cursor Cloud / Copilot cloud / remote Claude. Cannot see a private GPU")

System_Ext(public_net, "Public internet", "ngrok, Cloudflare Tunnel, port-forward of 11434. Forbidden")

Rel(dev, lab, "Uses desktop IDE and reviews MCP results")
Rel(lab, premium, "Premium agent calls the vendor model for planning and review")
Rel(dev, cloud_agent, "May use separately", "out of scope for this MCP")
Rel(cloud_agent, lab, "Must not reach", "no private Ollama")
Rel(lab, public_net, "Must not publish Ollama")
```

**Trust boundary.** Inference stays on a private host. The premium
agent still sees the repo and the tool results. Local is not an air gap.

## Level 2 — Containers

One MCP process on the workstation. One Ollama HTTP API on the
inference host. Workstation and inference host may be the same
machine.

```mermaid
C4Container
title Containers — workstation MCP and private Ollama

Person(dev, "Developer")

System_Ext(premium, "Premium model API")

System_Boundary(ws, "Workstation") {
    Container(ide, "Desktop IDE", "Cursor / Copilot / Claude Code", "Premium agent orchestrates; applies or rejects local output")
    Container(mcp, "local-coding-slm", "Python FastMCP, stdio", "Bounded tools. No file writes. No shell. No listen port")
    Container(env, "gitignored .env", "OLLAMA_*", "Private URL and model tags. Never committed")
}

System_Boundary(inf, "Inference host") {
    Container(ollama, "Ollama", "HTTP API", "Loopback by default. Optional private-interface bind")
    Container(fast, "Fast SLM", "qwen3.5:9b", "Everyday mechanical generation")
    Container(strong, "Strong SLM", "devstral-small-2", "Harder local coding; agent escalates")
}

Rel(dev, ide, "Prompts, reviews, applies")
Rel(ide, premium, "Planning and final review")
Rel(ide, mcp, "MCP tool calls", "stdio")
Rel(mcp, env, "Reads settings at start")
Rel(mcp, ollama, "POST /api/chat, GET /api/tags", "http://<inference-host>:11434")
Rel(ollama, fast, "Loads default model")
Rel(ollama, strong, "Loads on model=strong")
```

The MCP server is the only process this repo ships. Ollama is operated,
not implemented here.

## Level 3 — Components (`local-coding-slm`)

Runtime path for a tool call. The deployment checker is a separate
batch job on the workstation; it does not sit on the request path.

```mermaid
C4Component
title Components — local-coding-slm on the workstation

Container_Boundary(mcp, "local-coding-slm") {
    Component(tools, "MCP tool surface", "server.py FastMCP", "local_status, local_code, local_refactor, local_generate_tests, local_explain, local_review")
    Component(prompts, "Fixed system prompts", "prompts.py", "One short prompt per tool. Premium agent supplies the task")
    Component(client, "Ollama client", "ollama_client.py", "fast/strong map, timeouts, num_ctx, chat and tags")
    Component(dotenv, "Env merge", "envfile.py / run_mcp.sh", "Loads .env. Empty IDE interpolations count as unset")
}

Container_Ext(ide, "Desktop IDE", "stdio MCP client")
Container_Ext(ollama, "Ollama", "HTTP")
Container_Ext(checker, "Deployment checker", "check_deployment_safety.py + safety.py")

Rel(ide, tools, "Tool call with task + selected files", "stdio")
Rel(tools, prompts, "Selects system prompt")
Rel(tools, client, "chat() or status_report()")
Rel(dotenv, client, "OLLAMA_BASE_URL and tags")
Rel(client, ollama, "JSON HTTP, stream=false")
Rel(checker, dotenv, "Inspects URL, tags, gitignore, local listen")
```

Tools receive snippets the premium agent chooses. They do not scan the
repository.

## Deployment variants (same containers)

Only one inference host is active. Change `OLLAMA_BASE_URL` (and
optionally an SSH forward). Do not add a second MCP server.

```mermaid
flowchart TB
  subgraph workstation["Workstation"]
    ide["Desktop IDE"]
    mcp["local-coding-slm stdio"]
    ide -->|"MCP"| mcp
  end

  subgraph current["Current lab — same machine"]
    local["Ollama on 127.0.0.1"]
  end

  subgraph t12["T12 — second NVIDIA host in WSL"]
    ssh1["ssh -L 11434:127.0.0.1:11434"]
    wsl["Ollama on WSL localhost"]
    ssh1 --> wsl
  end

  subgraph p4["Phase 4 — Halo-class AMD"]
    ssh2["ssh -L 11434:127.0.0.1:11434"]
    halo["Ollama + ROCm on Halo localhost"]
    ssh2 --> halo
  end

  mcp -->|"active now"| local
  mcp -.->|"when T12 host is on"| ssh1
  mcp -.->|"future, after Phase 3"| ssh2
```

Prefer SSH local-forward over a LAN bind for T12 and Halo. A
private-interface bind plus a workstation-only firewall is optional.
Public tunnels are out of scope.
